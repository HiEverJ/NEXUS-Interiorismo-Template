POSICIONAMIENTO PROPUESTO
NEXUS — Interior Architecture HTML Template
Una página para estudios pequeños de arquitectura interior que necesitan presentar su enfoque, materiales y proyectos con una estética sobria.
Público: diseñadores/desarrolladores que personalizan HTML para estudios; requiere conocimientos básicos de HTML y CSS.
Diferenciador: recorrido por materiales, galería horizontal y dos paletas, con navegación accesible y versión móvil de lectura clara.

BORRADOR DE DESCRIPCIÓN DE VENTA (EN INGLÉS)
NEXUS is a single-page HTML template for interior architecture studios. Its editorial layout pairs a desktop sidebar with a mobile section menu, a material explorer and a horizontally scrollable project gallery. Light and dark palettes let you adapt the presentation to your studio.

Included: one HTML page, compiled CSS, optional Sass source files, vanilla JavaScript, local image placeholders and an HTML setup guide.
Features: responsive navigation, native material disclosures, keyboard gallery controls, reduced-motion support, optional saved theme preference and email contact link.
Requirements: basic HTML/CSS editing and static hosting.
Not included: stock photographs, bundled fonts, hosting, domain, CMS, visual editor, form backend or customization service.
Demo projects and studio details are fictional. Photography shown in the demo is not included in the download. Optional Google Fonts are loaded remotely.
